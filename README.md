### 📉 Loan Default Risk Dashboard
**Problem** — Lenders approved loans without a clear view of which borrower segments actually default.

**What I did** — Modeled loan data across demographics, credit score bands, employment type and financial-risk metrics into an end-to-end Power BI dashboard.

**Outcome** — Isolated the high-risk segments driving the majority of defaults and exposed them as drill-down KPIs, so credit decisions can be filtered by risk band in seconds instead of manual review.

`Power BI` · `DAX` · `Data Modeling` · `Risk KPIs`

[**→ Open dashboard repo**](https://github.com/Mrityunjai-hue/Loan-Default-Dashboard)

</td>
<td width="50%" valign="top">

### 🤖 Loan Agent Platform
**Problem** — Loan applications were assessed manually, slowly and inconsistently.

**What I did** — Built a Python platform that ingests applicant data, scores it and returns an explainable recommendation.

**Outcome** — Converted a manual review step into an automated, repeatable scoring flow with consistent criteria on every application.

`Python` · `Automation` · `Modeling` · `Explainability`

[**→ Open project**](https://github.com/Mrityunjai-hue/Loan-Agent-Platform)

</td>
</tr>
<tr>
<td width="50%" valign="top">

### 🧭 Career Intelligence
**Problem** — Students pick skills blindly, without market signal.

**What I did** — Built a data product mapping roles → required skills → demand signals into an explorable interface.

**Outcome** — Turns scattered job-market data into a single ranked view of which skills actually move hiring odds.

`TypeScript` · `Data Product` · `Insight Design`

[**→ Open project**](https://github.com/Mrityunjai-hue/career-intelligence)

</td>
<td width="50%" valign="top">

### ⚙️ n8n Data Science Web App
**Problem** — Repetitive ingest → clean → report cycles ate analysis time.

**What I did** — Built n8n automation pipelines wired to a web app for scheduled data pulls and reporting.

**Outcome** — Removed the recurring manual refresh step, so reporting runs on a schedule instead of on demand.

`n8n` · `ETL` · `Pipelines` · `TypeScript`

[**→ Open project**](https://github.com/Mrityunjai-hue/n8n-ds-webapp)

</td>
